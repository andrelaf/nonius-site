Dense time series, exact to the nanosecond at any zoom.

Millions of points in a browser, a desktop program or a server's images, every one where it belongs however far you zoom in. One Rust core summarises a series on the server and draws it on the screen.

On crates.io and npm; the .NET packages are coming to NuGet.

Why Nonius

Exact at deep zoom

A chart that keeps time as a 32-bit float, as GPU charts commonly do, cannot tell apart two instants of 2025 less than about two minutes apart. Nonius keeps time as 64-bit nanoseconds until the start of the visible window has been taken off; only the small offsets that remain become floats.

One core, from server to pixel

The server's tiles and images and the browser's frame come from the same Rust code, compiled to WebAssembly for the page. A page that puts tiles together draws what a page holding the whole series draws, and the server's PNG is the browser's frame.

Its own format, read in place

A series travels as NSB1: little-endian columns aligned to 64 bytes, the layout of Arrow buffers. The browser copies the bytes once into the chart's memory and reads them there: no JSON, no decoder. A live feed is numbered frames on a WebSocket, and a lost one is recovered.

How it works

A point travels from your data to the screen in five steps, none of them a translation:

  1. The point: a time in nanoseconds, a value and a weight, three 64-bit integers, so nothing is rounded.
  2. NSB1: the points as columns, each starting on a multiple of 64 bytes, read where they lie.
  3. The pyramid: summaries at every zoom, and a view reads the level that fits its pixels.
  4. Tiles over HTTP: fixed pieces at addresses that never change, cached for a year.
  5. The live feed: numbered frames, so a lost one is noticed and recovered.

How it fits

The same Rust core runs on your server, in your page and in native programs. Between server and page travel only three things: tiles, a live feed and images.

Use it

A point is a time in nanoseconds, a value and a weight. A value is an integer of a fixed number of decimal places, so 101.25 stays 101.25 from your data to the frame.

Your own data: a CSV, with no code

nonius-server csv prices.csv prices.nsb

It comes with cargo install nonius-server. It finds the decimal places, reads ISO 8601 times and a spreadsheet's semicolons and decimal commas, and stops at the first line it cannot read, saying which. nonius-server prices.nsb then serves the file.

From a program, the same file comes from each package, byte for byte: Rust's write_series, .NET's Nsb.Encode, C's nonius_nsb_write, and encodeNsb in JavaScript, in the browser or in Node.

Rust: a series file to a picture, with no GPU

cargo add nonius-format nonius-core
cargo add nonius-render --no-default-features

Read the file in place, keep it as a pyramid of summaries, and draw any view of it, here the whole series:

use nonius_core::{Loaded, Pyramid, Series, Width, Zone};
use nonius_format::{AlignedBytes, Container};
use nonius_render::{Still, Theme, still_png};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Read once into memory aligned for the columns, then read in place.
    let bytes = AlignedBytes::from_slice(&std::fs::read("day.nsb")?);
    let container = Container::parse_checked(bytes.as_slice())?;
    let series = Series::from_container(&container)?;

    // Summaries from one second up, nine levels (see nonius-core's
    // "Choosing the pyramid").
    let mut pyramid = Pyramid::new(Width::new(1_000_000_000)?, 9)?;
    pyramid.extend_sorted(series.iter())?;
    let loaded = Loaded::new(&pyramid, (series.t(), series.v(), series.w()));

    let (Some(&first), Some(&last)) = (series.t().first(), series.t().last()) else {
        return Err("the file holds no points".into());
    };
    // The image's size is in device pixels; `ratio` scales labels and lines.
    let png = still_png(&loaded, &Still {
        start: first,
        end: last + 1,
        width: 2400,
        height: 800,
        theme: Theme::light(),
        ratio: 2.0,
        scale: series.scale(),
        gap: None,
        zone: Zone::UTC,
    })?;
    std::fs::write("day.png", png)?;
    Ok(())
}

An image says where its plot is and what it spans, so a click on it picks the exact point and a mark drawn over it lands where the line is: the server's /png answers Nonius-Plot and Nonius-Range, and still_placement, C's nonius_still_placement and .NET's Series.StillPlacement give the same numbers.

The browser: a chart a person can pan and zoom

npm install nonius
const chart = await createChart(canvas);

// Your points: times in nanoseconds since 1970 as BigInts, values as
// integers with a fixed number of decimal places (2 here: 10_000 is
// 100.00), and a weight each.
const { t, v, w } = randomWalk();
chart.setScale(2);
chart.push(t, v, w);

// Open on everything, the value axis fitted to it.
const [start, end] = [t[0], t[t.length - 1] + 1n];
const [lo, hi] = chart.autoscale(start, end, 0, 8);
chart.setView(start, end, lo, hi);

WebGPU where the browser has it, WebGL2 otherwise, and a 2D canvas when neither gives a device. The package also follows a server's tiles and streams a live feed from a worker; React and Vue use it as any other module.

A sensor that reports in bursts draws a straight line from one burst to the next unless you say how long a pause is a gap: chart.setSeriesGap(id, ns) breaks the line wherever a point comes more than ns nanoseconds after the one before, in the same places at every zoom.

Time is labelled in UTC until you name a zone: setTimeZone(chart, "Europe/Lisbon") labels the axis, the crosshair and the tooltip in its local time, on both sides of each daylight-saving change, from the browser's own time zone data. The server's images take tz=, and the .NET chart a TimeZoneInfo.

.NET: the same core, from C#

dotnet add package Nonius
using var series = Series.FromNsb(File.ReadAllBytes(nsb));
if (!series.TryGetRange(out var first, out var last))
{
    throw new InvalidDataException($"{nsb} holds no points");
}
// Light, for a box of 1200 × 400 CSS pixels at a pixel ratio of 2:
// the size is in device pixels, the ratio in thousandths.
byte[] image = series.StillPng(new Still(first, last + 1, 2400, 800, Theme.Light, RatioPermille: 2000));
File.WriteAllBytes(png, image);

Nonius.Avalonia is a desktop chart control, and Nonius.Blazor a component carrying the browser package.

Specifications

The wire protocol is written to be implemented without reading Nonius's code: a client was written from it alone, and its columns match the core's.

  • The protocol: a history in tiles over HTTP, and its images.
  • The pyramid file: a series and its summaries, read in place.
